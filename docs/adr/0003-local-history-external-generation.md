# Keep practice history local and use the existing ChatGPT plan

The first version runs in a browser on the Candidate's computer and saves study material, tests, and results locally. It uses the Candidate's existing ChatGPT Plus plan for eligible AI requests, without a separate paid API key; selected pages, images, or extracted text may leave the computer for question generation. The app makes that transfer visible and stops AI generation when included usage is unavailable rather than incurring an additional charge.
