# Android student app

## Scope and mode

Operate. Android-first, camera-first native student experience; preserve the existing computer-hosted backend and separate web admin panel. No public deployment or store publication is part of this change.

## Direction contract

THESIS: Photograph today's learning, answer three questions, and send a study moment to an accepted mate. The camera is the starting destination.

OWN-WORLD: Translate MockTaste's indigo, navy, and green into Material 3 color roles. Use system Android type, native Material controls, tonal surfaces, standard Back handling, edge-to-edge insets, and matched light/dark themes.

STORY: Sign into a workspace, allow camera access, capture and preview a page, complete the mini quiz, select mates, send, and return to the inbox or shared streak. Personal notes and tests remain available in Study.

FIRST VIEWPORT: A top app bar, full available-height native camera, readable capture prompt, shutter and flash/switch controls, and five Material navigation destinations: Camera, Snaps, Mates, Study, Profile. Permission refusal shows an actionable recovery screen. Expanded width uses a side drawer.

FORM: User-pinned camera-first Android extension of the existing product. No new brand or image comp. The signature interaction is the camera-to-private-quiz-to-mates sequence, backed by the same sharing gate and streak rules as the web app.

FINISH: The APK is compiled, signed for internal testing, and installed and checked on an Android 36 Pixel 6 emulator. Native screenshots cover light/dark appearance, 1.3 font scale, and an expanded-width override. Camera capture, quizzes, sharing, notes, tests, Back, session restoration, and offline startup sign-out pass the device workflow. See android-verification.md for evidence and the limits of fixture-based AI testing.
