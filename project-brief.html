Project brief

MockTaste

A private study workspace that helps learners turn their notes into practice tests and track what they have learned.

What it does

MockTaste started as an RRB NTPC exam practice tool and now supports personal study across subjects. Learners add notes or documents, generate multiple-choice tests, take timed practice, review explanations, and follow their progress.

Study library

Organize notes, PDFs, Word files, and images in a personal workspace.

Practice tests

Build tests from selected material, with answers checked against evidence.

Review and progress

See scores, explanations, topic results, and completed practice history.

Private by default

The app runs on the learner’s computer and stores study history locally.

How deep learning is used

Deep learning powers language models that can read text and produce new text. In MockTaste, the current app can use the learner’s connected ChatGPT service to read scanned pages and draft questions from selected study material. A second AI pass checks answers. The app itself manages saved tests, timers, scores, and review.

The project also includes an experiment to fine-tune a small open model, Qwen2.5-0.5B-Instruct, using QLoRA. This trains a small adapter to better follow MockTaste’s question format while keeping the base model mostly frozen. It is an experiment, not a model trained from scratch.

Current status: the fine-tuned model is not connected to the app and is not ready for student use. The first run used 8 training examples and 2 evaluation examples. It learned the output format in this tiny sample, but a generated question had a wrong answer. More data and much stronger review are needed before judging quality.

Why explore fine-tuning?

A model tailored to the project might follow the required format more consistently and could eventually run locally. These are goals to test, not proven results. A useful evaluation needs many examples kept separate from training, checks that answers are correct and supported by sources, and human review for clarity and ambiguity.
