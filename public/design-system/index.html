Use the system only

  • Choose a documented component and variant before adding a new style.
  • Define colors, dimensions, type, depth, and motion in tokens.css. Components consume those tokens.
  • Compose page layouts in patterns.css. Feature stylesheets must not override shared components.
  • Keep loading, disabled, focus, error, and reduced-motion states part of the component.
  • Add new shared components here before using them in a screen.
